# Prose hygiene (bundled be-human)

*Condensed from the be-human skill so this writer works standalone. If the full `be-human` skill is installed, prefer it, since it may be newer. Apply in both directions, drafting clean from the start and scrubbing once before delivery.*

The principle is that these tics add shape without adding information. Real writing earns its emphasis, so if a sentence says the same thing with the flourish removed, remove it. The tell is density and reflexiveness, not any single word.

**The catalog, compressed:**

1. **Inflated significance.** "stands as a testament," "pivotal role," "lasting legacy," "watershed moment." State what happened with numbers, because significance shown beats significance asserted. (Deadly in exec docs, since a board smells inflation instantly.)
2. **Promotional tone.** "world-class," "cutting-edge," "robust," "seamless," "boasts." Concrete detail beats adjectives, and this is already the numbers-over-adjectives register rule.
3. **Editorializing asides.** "it's important to note," "notably," "interestingly." Delete them and the sentence survives.
4. **Filler transitions.** Reflexive "moreover / furthermore / additionally / however." Plain sequence or a single "and"/"but" reads better.
5. **Reflexive summaries.** "In conclusion / In summary / Overall" capping short passages. State the takeaway once, plainly, or let the last substantive sentence end it.
6. **Negative parallelisms.** "It's not X, it's Y," "not only… but also." Just say Y.
7. **Rule of three.** Everything arriving in triplets. Use one adjective if one is true, four items if there are four, and break the rhythm.
8. **False ranges.** "from startups to enterprises." Name what you actually mean.
9. **Trailing "-ing" editorializers.** "…, reflecting a broader trend," "…, ensuring resilience," "…, underscoring our commitment." Cut them, or promote to a sourced sentence. (The "ensuring" variant infests infrastructure writing specifically.)
10. **Weasel attribution.** "experts say," "studies show," "industry reports suggest" with no source. Name the source or drop the claim. In regulator-facing text this is disqualifying.
11. **Filler openers.** "In today's fast-paced world…" The test is whether the sentence could open a document on any other subject. If it could, delete it.
12. **Formatting overkill.** Bold everywhere, lists where prose belongs, "**Scalability:** the system scales" bold-label bullets, emoji decoration. Default to prose, and format only when structure genuinely calls for it.
13. **Punctuation, per the owner skill.** Follow the punctuation preferences stated in the owner skill. If none are stated, use this default so the system's own prose stays clean. Em dashes are avoided in generated prose, rewritten as a comma, a period, or parentheses. Semicolons are avoided almost entirely (split the sentence). Colons appear only where they genuinely introduce a list or definition, never as mid-sentence rhythm. If colons or semicolons appear more than once or twice on a page, rewrite into shorter sentences. Ranges still take en dashes (1990–2000, a 3–2 vote). Text the user supplies and direct quotes are exempt.
14. **Section-template tells.** Challenges / Future Outlook / Conclusion sections present because the template has slots rather than because the content demands them. The anatomies in this skill define structure, so add nothing beyond what the content requires.
15. **Chatbot residue.** "I hope this helps," "As an AI," restating the request, sycophantic openers, unfilled template fill-ins. Finished documents address the reader, never the conversation that produced them.

**Never residue under #15.** `[X min]`-style placeholders and T2 labels survive the scrub (T13 scrub, ladder line 2), and every delivery notes the placeholders that remain.

**Final pass, highest yield for exec documents.** Cut every editorializing aside. Apply #13's punctuation, and justify or kill every trailing "-ing" clause. Thin clustered triples and "however/moreover". Kill any "It's not X, it's Y". Test the opening line for genericness, because the first sentence of a board memo must be true of this memo only.
