# asset-estate obligations

*One block per open-source license family in use, written by parvis-itam. SBOM data comes from the pipeline that parvis-sdlc owns, and this file holds only what the licenses in it oblige and where an obligated component is deployed. No legal conclusions, since that is counsel's call. Schema in parvis-memory section-templates.*

## <License family>
- **Obligation class:** <notice / source availability / reciprocity on modification / network-use reciprocity / patent or attribution condition>
- **Deployment shape that fires it:** <what has to be true for the obligation to bite, for example shipped to a customer, linked into a distributed artifact, or reached over a network>
- **Where it is deployed:** <estate view at component altitude, no repository paths or hostnames>
- **State:** satisfied / action needed / unknown
- **Routing to legal:** not routed / open with counsel (<date>) / cleared (<date>, in the user's own paraphrase)
- **Last reviewed:** <date> (<what prompted it>)
