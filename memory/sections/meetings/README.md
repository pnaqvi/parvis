# meetings standing-meeting threads

*One file per recurring meeting, named `<meeting-slug>.md`. It records decisions, items owed each way and carry-forwards. Opened by every prep, closed by every debrief.*

*Alongside the meeting threads, this section carries the three standard registers, `positions.md`, `decisions-ledger.md` and `insights.md`, so stances held about how these forums run, and decisions taken in them, have a home.*
