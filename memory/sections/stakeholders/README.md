# stakeholders registry

*One file per stakeholder, `registry/<person-slug>.md`, on the full schema in the parvis-stakeholders craft reference. It carries the professional dimension, motivation, the glass-test-bounded personal dimension, projects and stakes, dated stances, two-way commitments, network and history, with tier and cadence target in the header. The section is confidential (sync: no) and a nested local-only git repo. parvis-stakeholders owns it, interaction captures and meeting debriefs feed it, and stakeholder reviews, weekly drift flags and meeting-prep read it.*

*Alongside the per-person registry, this section carries the three standard registers, `positions.md`, `decisions-ledger.md` and `insights.md`, so stances held about engagement itself and decisions taken about relationships have a home. Commitments owed each way are recorded in the person file and, once promised in a sent artifact, also as a row in `portfolio-planning/commitments-ledger.md` under T12.*
