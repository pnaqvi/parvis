# system insights (friction log)

*One line per friction event. Head it `## YYYY-MM-DD - <slug>` and record what happened, which skill, and what should change. A line is offered first and written on a yes or on "log this friction" (T7 friction). A waiver line is written without an offer and records the rule and the date, never the content (ladder line 3, T4 consent).*
